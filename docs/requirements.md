# 요구사항

LMS 1305(미니 DBMS)의 문장을 그대로 옮기고, 우리 해석과 충족 여부를 적습니다. 문장 아래의 하위 항목은 괄호 안에 이어 적습니다. 칸의 쓰는 법은 `CONVENTION.md`의 "문서 역할"을 따릅니다.

- `해석`: 문장이 여러 뜻으로 읽힐 때 우리가 고른 뜻입니다. 분명하면 `—`입니다. 최종 PRD가 정해지면 채웁니다.
- `충족`: `—`(진행 전), `부분`, `충족`, `범위 밖` 중 하나입니다.
- `근거`: 그 판정을 받치는 테스트 ID와, 진짜 설계 결정일 때만 ADR 이름입니다. 성능을 재는 요구사항은 측정 기록의 링크를 적습니다.
- `남은 일`: 아직 못 한 것과 일부러 하지 않는 것입니다.
